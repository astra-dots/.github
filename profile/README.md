# Astra Dots

A configuration ecosystem for Arch Linux, KDE Plasma 6.4, and the Quickshell desktop environment.

---

## Repositories

- [**dotfiles**](https://github.com/astra-dots/dotfiles): The primary configuration repository. Contains system configurations for the SDDM login theme, KDE Plasma, Kitty terminal, Starship prompt, Matugen color extraction, Spicetify, and automated installation scripts.
- [**caelestia-kde**](https://github.com/astra-dots/caelestia-kde): Technical fork of the Caelestia Quickshell desktop shell. Contains over 70 architectural refinements including state indicators, expandable clipboard history, synchronized lyric displays, and interface optimizations.
- [**astra-dots.github.io**](https://github.com/astra-dots/astra-dots.github.io): Source repository for the project documentation portal and showcase website.
