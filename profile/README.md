# 🌌 Welcome to Astra Dots

**A curated Material Design 3 Linux desktop ecosystem powered by Arch Linux, KDE Plasma 6.4, and Quickshell.**

---

### 📂 Repositories

- [**`dotfiles`**](https://github.com/astra-dots/dotfiles): The master repository containing our custom Material You SDDM greeter, KDE shortcuts & rules, Kitty terminal, Starship prompt, Matugen, Spicetify, and non-destructive installer scripts.
- [**`caelestia-kde`**](https://github.com/astra-dots/caelestia-kde): Our fork of Caelestia KDE featuring 70+ custom refinements (synced lyric visualizers, Show Desktop indicators, typography harmonization, custom shader bloom, and instant responsiveness).
- [**`astra-dots.github.io`**](https://github.com/astra-dots/astra-dots.github.io): The official showcase website and interactive documentation portal.
